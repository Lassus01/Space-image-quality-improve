# SpaceEnhance AI EDSR

Проект представляет собой графический интерфейс (GUI) для улучшения качества космических изображений, основанный на модели машинного обучения EDSR (Enhanced Deep Residual Networks for Single Image Super-Resolution). Проект состоит из React-фронтенда и FastAPI-бэкенда.

## Особенности
* **Улучшение изображений**: Использование нейронной сети EDSR для супер-разрешения изображений (увеличение разрешения и детализации).
* **Современный интерфейс**: Фронтенд разработан на React + Vite с использованием Tailwind CSS для удобного и быстрого взаимодействия.
* **Поддержка AMD GPU**: Модифицированный бэкенд FastAPI использует библиотеку `torch-directml`, обеспечивая аппаратное ускорение на видеокартах AMD (для предотвращения фрагментации памяти применен патч на слоях свертки).
* **Построение графиков по ГОСТ**: Бэкенд включает автоматическую генерацию графиков обучения (Loss/PSNR), оформленных по академическому стандарту (оси, сетка, подписи на русском языке).
* **Подготовка датасета**: Специальный API-маршрут для быстрой подготовки обучающих данных с имитацией деградации космических изображений.

## Структура проекта
- `GUI/` — Фронтенд на React и Vite. Включает графический пользовательский интерфейс для работы с моделями и датасетами.
- `EDSR-PyTorch/` — Исходный код модели EDSR, используемый бэкендом для обучения и инференса.
- `api.py` — Основной файл FastAPI-бэкенда, объединяющий фронтенд и модель.

## Системные требования
- Python 3.8 или выше (рекомендуется для бэкенда)
- Node.js 18+ и npm (для фронтенда)
- Установленный драйвер для работы с DirectML (при использовании GPU от AMD)

## Установка и запуск

### 1. Настройка и запуск Backend (Серверная часть)

Для запуска бэкенда рекомендуется создать виртуальное окружение.

```bash
# Клонируйте репозиторий и перейдите в корневую папку проекта
git clone <URL репозитория>
cd <название_репозитория>

# Создайте и активируйте виртуальное окружение
python -m venv venv

# Для Windows:
venv\Scripts\activate
# Для Linux/macOS:
source venv/bin/activate

# Установите необходимые зависимости
pip install -r requirements.txt

# Запустите FastAPI сервер
python api.py
```
Сервер запустится на `http://0.0.0.0:8000`.

### 2. Настройка и запуск Frontend (GUI)

Откройте новый терминал и выполните следующие команды:

```bash
# Перейдите в папку GUI
cd GUI

# Установите зависимости
npm install

# Запустите сервер для разработки
npm run dev
```
Фронтенд запустится и будет доступен по адресу `http://localhost:5173`.

## API Эндпоинты
Бэкенд предоставляет следующие основные REST-маршруты:
- `GET /` — Проверка статуса сервера.
- `POST /api/prepare_dataset` — Подготовка датасета с деградацией (ухудшением) изображений.
- `POST /api/train` — Запуск асинхронного процесса обучения модели EDSR.
- `GET /api/training_status` — Получение статуса текущего обучения.
- `GET /api/metrics` — Чтение метрик из логов (Loss, PSNR).
- `GET /api/generate_plot` — Генерация графика метрик в формате Base64 по ГОСТу.
- `GET /api/models` — Список доступных обученных моделей (`.pt`).
- `POST /api/enhance` — Загрузка изображения для обработки моделью и получение улучшенной версии.
